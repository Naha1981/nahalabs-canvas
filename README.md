# NahaLabs Canvas

An original NahaLabs visual systems map with evidence labels. Every card is tagged Verified, Observed, Claim, Inference or Unknown, has an owner and a next action, and the map exports as a brief that lists the open gaps.

Templates: Council stage map, CargoIQ case map, Flavourly journey, RevenueDesk lead flow.

Limits: the map is a view and a set of notes. It reads and writes no product records, and moving a card never counts as an approval. Boards are saved in the browser on the device. Use Save JSON to move a board.

Owned by NahaLabs (Pty) Ltd. Open-source component licences are listed in package-lock.json.

    npm install
    npm run dev
    npm run build
